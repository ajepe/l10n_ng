# Nigeria Localization

Odoo 18 addons for Nigeria.

## Modules

- [`l10n_ng_address`](l10n_ng_address/README.md): Nigerian states and Local
  Government Areas for contacts. Adds an LGA field filtered by state and
  includes the LGA in formatted addresses.
- [`l10n_ng_address_website_sale`](l10n_ng_address_website_sale/README.md):
  shows the LGA field in the eCommerce checkout address form. Installs
  automatically with `l10n_ng_address` and `website_sale`.
